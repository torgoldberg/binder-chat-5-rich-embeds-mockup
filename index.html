Design notes (for PM → Issue)

Bubble anatomy: message text (optional) → muted URL line (always kept in body) → embed card attached inside the same bubble. Card = 56×72 thumb (catalog square 56) + kind label + 2-line title + live money + full-width CTA (44pt). Gold solid CTA for commerce entry (Bid / Buy / See listings); ghost for nav-only (View listing / View). Prefer hiding CTA on own posts over a disabled control. Deal threads reuse DM chrome — same embed component. Spacing/animation left to developer; hierarchy and CTA mapping are sealed here.
